# Ride Booking History System

Copyright (c) 2026 Sujan. All rights reserved.

A Java console project that manages ride history using a linked list.

## Features

- Add a new ride at the end
- Cancel the last ride
- View all rides
- Search rides by pickup or drop location
- Reverse ride history to show latest rides first

## Project Structure

```text
src/
  Main.java
  Ride.java
  Node.java
  RideHistory.java
```

## Compile and Run

```powershell
javac -d out src/*.java
```
